Website SEO Privacy Policy

Personal website

Scope

This policy describes Website SEO, the private administration tool operated by Ebrahim M. Songhori for esonghori.com. It covers the tool's use of Google APIs.

Information accessed and its purpose

With the owner's authorization, the tool accesses Google Analytics reports and property settings, plus Google Search Console properties, search-performance reports, URL inspection results, and sitemap information. It uses this information to assess website performance, diagnose issues, and make authorized configuration or website improvements.

The tool uses Google OAuth authorization. It does not receive or store the Google account password.

Storage and processing

OAuth client configuration, access and refresh tokens, connection details, and saved reports are stored on the owner's computer with access restricted to the owner's operating-system account. They are kept outside the public website repository.

Selected API responses and reports may be sent to an AI assistant provider, such as OpenAI, to help analyze findings and prepare website changes. That provider's processing and retention depend on the owner's account settings and the provider's policies. OAuth credentials are used locally to authenticate Google API requests and are not included in reports.

The tool does not sell Google user data or use it for advertising targeting. Google API data is used for the website administration purposes described here.

Retention and control

Local credentials and reports remain on the owner's computer until deleted. Access can be revoked through the Google Account's third-party connections settings. Revoking authorization stops future API access; previously saved local files can be deleted separately. Copies in an AI assistant conversation are managed through that provider's controls.
