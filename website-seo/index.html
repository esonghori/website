About this tool

Website SEO is a private administration tool operated by Ebrahim M. Songhori for esonghori.com. It reviews Google Analytics and Google Search Console data to understand site traffic, check indexing and sitemaps, and identify website improvements.

The tool can read Analytics reports and settings, update supported Analytics settings, inspect Search Console information, and submit sitemaps using the account owner's authorization. It runs locally and is intended for the site owner's use.

Selected reports may be processed with an AI assistant to help interpret findings and make website changes.
